# T11 · 思维导图（目标拆解树）

> 定位：**不是**自由白板，也**不是**知识库。它只做一件事——把一个目标拆成能执行的节点，并且能一键变成任务。

## 0. 目标

- 画布可缩放平移，节点是树（一个根 + 若干分支），自动左右布局，也允许手动拖拽微调。
- 节点可一键转成任务（带 `goalId`），任务完成后节点显示勾。
- 一个目标一棵树；从 OKR / Goal 直接「生成导图」时自动带入子节点。

## 1. 前置

- T03 完成（Goal/Task 仓储、TaskCard 可复用）、T02 完成（画布容器、`motion`）。
- 契约：`MindMap`、`MindNode`（`mapId/parentId/x/y/kind/refId/collapsed`）。

## 3. 交互规格

### 3.1 画布

- 背景：点阵网格（`radial-gradient` 实现），缩放 25%–200%。
- 平移：空白处拖拽 / 空格 + 拖拽 / 双指拖动。
- 缩放：`Ctrl + 滚轮`、触控板双指、右下角 `+ / − / 适应画布`。
- 渲染：`transform: translate(x, y) scale(z)`，节点用绝对定位。

### 3.2 节点

| 操作 | 行为 |
| --- | --- |
| 单击 | 选中（显示浮动工具条） |
| 双击 | 就地编辑文本（textarea 自动宽高） |
| `Tab` | 在选中节点下新建子节点 |
| `Enter` | 在选中节点后新建兄弟节点 |
| `Delete` | 删除节点及其子树（确认或撤销） |
| 拖拽 | 调整位置（`x/y` 落库，脱离自动布局） |
| 折叠 | 节点左侧小圆点，收起子树 |
| 拖到另一节点上 | 改变父节点（带吸附高亮） |

### 3.3 自动布局

- 默认「左右树」：根在中间，子节点向两侧分层（按深度 `x = depth * 220`，按顺序 `y` 递增 64）。
- 布局只在节点结构变化时重算；手动拖过的节点标记 `pinned`（用 `x/y` 是否有值判断），不参与自动布局。
- 连线用 SVG 贝塞尔曲线（`M ... C ...`），线宽 1.5，颜色 `--border-strong`，选中路径高亮。

### 3.4 节点类型

- `idea`（默认）、`goal`（引用某个 Goal）、`task`（引用某个 Task）、`kr`、`note`
- 节点上显示小图标 + 引用实体标题（只读），点击跳转。
- 浮动工具条：`转任务`、`关联目标`、`上色`、`折叠`、`删除`。
- 「转任务」：把节点文本作为标题建任务（`goalId = map.goalId`），节点变 `kind: "task"`、`refId = taskId`，任务完成后节点打勾 + 文字变灰。

### 3.5 从目标生成

- `新建导图` 时可选「从目标生成」：根节点 = 目标标题，第一层 = 目标下的任务（最多 12 个）。
- OKR 页的「生成导图」按钮（T09 预留入口）：根 = Objective，一层 = KR，二层 = 关联任务。

## 4. 性能

- 500 节点以内保持 55fps：节点用 `React.memo`，拖拽时只更新被拖节点的 transform（用 ref 直接改 style，不走 React state）。
- 连线用单个 `<svg>` 覆盖层，避免每个节点一个 svg。
- 视口外节点不渲染（简单裁剪：`x/y` 超出可视范围 ±400px 时跳过）。

---

## 5. 验收

1. 新建导图 → 加 5 个节点 → 布局正确、连线正确。
2. 双击改名 → 刷新后仍正确。
3. `Tab`/`Enter` 新建节点，键盘可完成整棵树。
4. 节点「转任务」→ 任务出现在四象限（Q2），关联到该目标；完成该任务后节点变灰打勾。
5. 拖拽节点到另一节点 → 父子关系改变，布局重排。
6. 折叠/展开、适应画布、缩放边界（25%/200%）正常。
7. 500 节点压力测试不卡（可造数据）。
8. 375 宽：画布可双指缩放，节点文字不溢出。
