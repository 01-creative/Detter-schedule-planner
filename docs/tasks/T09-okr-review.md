## 3. OKR 页面

### 3.1 周期导航

```
‹  2026 Q4  ›    [周] [月] [季] [年]     [+ 新建 Objective]
```
- 默认打开当前周期的 `月`。
- 切换周期时若该周期没有 OKR，显示空态「这周还没有目标」+ 从上一周期复制的入口。

### 3.2 Objective 卡片

```
┌─────────────────────────────────────────────────────┐
│ ● 把英语听力拉上来                    进度 42%  [⋯]  │
│   KR1  每周精听 3 次          2 / 3    ▓▓▓▓▓▓░░ 67%  │
│   KR2  完成 20 篇 TED 精听    8 / 20   ▓▓▓░░░░░ 40%  │
│   KR3  六级模考 ≥ 550         520      ▓▓▓▓▓░░░ 52%  │
│   关联任务 6 项 · 关联目标 2 个      [+ KR] [关联]   │
└─────────────────────────────────────────────────────┘
```

- Objective 进度 = 所有 KR 进度均值。
- KR 进度：`metricType` 决定算法
  - `percent`：`(cur - start) / (target - start)`
  - `number`：`cur / target`
  - `boolean`：0 或 100%
  - `milestone`：已完成里程碑数 / 总数
- 进度条可**直接拖拽**更新（拖动时显示数值气泡），松手写库。
- KR 上可挂「自动推进」：`linkedTaskIds` 里的任务全部完成 → 进度 +1（仅 `number` 型且 `step` 明确时）；默认关闭，避免误伤。

### 3.3 关联

- `[关联]` 打开选择器：可挂已有 Goal 与 Task；挂上后双向可见（Goal 上显示 OKR 标签）。
- 任务在四象限里显示所属 KR 的小色点（由 T03 的 TaskCard 预留了 `goal`，这里通过 `task.okrId` 传色）。

## 4. 复盘

### 4.1 触发

`/review` 或 `/review?range=month`。顶部选择范围：本周 / 上周 / 本月 / 上月。

### 4.2 内容（自动生成，无需 AI）

```
本周复盘 · 11/24 - 11/30

完成 9 项，新增 14 项，逾期 2 项
四象限分布：Q1 4 / Q2 10 / Q3 3 / Q4 2   ← Q2 占比 52%（健康）
专注：12 个番茄 · 5 小时 20 分（目标 15 小时，达成 36%）
KPI：健身 3/3 ✅ 读书 120/200 ⚠️
目标推进：高数不挂科 40% → 55%（+15%）
本周做得好的：...
值得注意的：Q1 有两项逾期；周三之后专注时长骤降
```

- 数据全部来自本地库，**不调用任何外部服务**。
- 「做得好的 / 值得注意的」用规则生成（完成率、逾期、Q2 占比、连续专注天数），不用模型。

### 4.3 导出

- `复制为 Markdown` → 剪贴板（可直接粘给 AI）
- `下载 .md`
- `下载 .json`（结构化，给 agent 用）
- 顶部固定提示：「想更深度的分析？把这份 Markdown 连同 `上下文包`（设置 → AI 接入）一起给 AI。」

### 4.4 历史

- 复盘按周期归档：生成过的复盘存在 `settings["review.<periodKey>"]` 里（快照），可回看。
- 不要每次打开都重算历史复盘——历史数据会变，快照才有意义。

## 5. 验收

1. 新建 1 个 Objective + 3 个 KR → 进度条显示正确。
2. 拖动 KR 进度条到 60% → 刷新后仍是 60%。
3. 把两个任务挂到 KR 上 → 卡片显示「关联任务 2 项」。
4. 完成其中一个任务 → KR 的 `linkedTaskIds` 完成数更新（若开启自动推进）。
5. 打开复盘 → 数字与四象限/KPI/番茄钟页面的口径一致（重点核对）。
6. 复制 Markdown → 粘贴出来格式正确（中文标点、表格不错位）。
7. 375 宽：OKR 卡片可读，进度条可拖。
