# T07 · 专注（番茄钟）与 KPI

> 四象限决定「做什么」，番茄钟回答「做了多久」，KPI 回答「有没有偏」。

## 0. 目标

1. 一个不会漂移、关了页面也不丢的番茄钟，并且能和具体任务绑定。
2. 一套可信的量化指标：既能手工打卡，也能从番茄钟/任务完成自动聚合。

## 3. 番茄钟

### 3.1 计时模型（关键：不许用 setInterval 累加）

```ts
// 唯一真相是「目标结束时间」
const endsAt = startedAt + planMin * 60_000;
// 每 250ms 渲染时用 Date.now() 反算剩余，而不是 remaining -= elapsed
```

- 页面刷新/切后台/锁屏后回来，剩余时间必须准确。
- 暂停 = 记录 `pausedAt`，恢复时 `startedAt += (now - pausedAt)`。
- 结束：写一条 `pomodoro` 记录（`endedAt`、`actualMin`、`completed: true`），播放提示音 + 系统通知（已授权时）。
- 中断（用户手动停止）：`completed: false`，`actualMin` 按实际累计。

### 3.2 页面布局（桌面）

```
┌──────────────────────────────────────────────────────┐
│   [专注 25:00]        ← 大圆环（SVG，直径 280）        │
│      ● ● ● ○          ← 本轮第几个番茄                │
│   [开始] [暂停] [跳过]                                 │
├──────────────────────┬───────────────────────────────┤
│ 当前任务              │ 今日统计                       │
│ ┌──────────────────┐ │ 专注 3 个 · 75 分钟             │
│ │ 交高数作业  [换]  │ │ 打断 1 次                      │
│ └──────────────────┘ │ 连续 4 天                      │
├──────────────────────┴───────────────────────────────┤
│ 最近记录（今天）                                       │
└──────────────────────────────────────────────────────┘
```

- 圆环：`stroke-dasharray` 动画，颜色随状态（专注=品牌紫、休息=翡翠、暂停=灰）。
- 背景：极淡的渐变光晕，随呼吸节奏 4s 缩放（`prefers-reduced-motion` 时关掉）。
- 任务选择器：搜索 + 最近任务 + 「不绑定任务」。

### 3.3 设置

读取 `settings["focus.pomodoro"]`：`{ focusMin, shortBreakMin, longBreakMin, longBreakEvery }`，默认 25/5/15/4。
提供设置面板（FocusPage 右上角齿轮），修改后立即生效（未开始的轮次）。

### 3.4 提醒

- 结束前 10 秒：轻微提示音（可用 WebAudio 合成，不引入音频文件）。
- 结束时：三声提示 + Notification（若已授权）。
- 页面标题同步显示剩余时间（`25:00 · Detter`），切标签页也能看到。

### 3.5 移动端

- 圆环缩小到 220，按钮加大到 56px 高。
- 支持「锁屏计时」：依靠 `endsAt`，回到前台时校正。

## 4. KPI

### 4.1 概念

一条 KPI = `名字 + 单位 + 周期 + 目标值 + 方向 + 聚合方式`。
例：`深度工作时长 / 分钟 / 每周 / 900 / up / sum（自动来自番茄钟）`。

### 4.2 页面

```
┌───────────────────────────────────────────────┐
│ KPI                       [+ 新建指标] [周期▾] │
├───────────────────────────────────────────────┤
│ ┌─────────────┐ ┌─────────────┐ ┌───────────┐ │
│ │ 深度工作时长 │ │ 健身次数     │ │ 读书页数   │ │
│ │ 620 / 900   │ │ 3 / 3       │ │ 120 / 200 │ │
│ │ ▓▓▓▓▓▓░░░ 69%│ │ ▓▓▓▓▓▓ 100% │ │ ▓▓▓░░ 60% │ │
│ │ 折线趋势     │ │ 柱状打卡     │ │ 折线       │ │
│ └─────────────┘ └─────────────┘ └───────────┘ │
└───────────────────────────────────────────────┘
```

- 图表用**手写 SVG**（不引入图表库），风格与设计令牌一致：2px 线宽、渐变填充、无网格线。
- 达标线用虚线；超过目标用绿色，低于 60% 用琥珀色。
- 点击卡片 → 展开该指标的每日明细 + 手工补录。

### 4.3 打卡

- 快速打卡：卡片上直接 `+1`（按 `unit` 累加）或输入数值。
- 补录：选日期 + 数值。
- 自动聚合：`autoSource` 非空的指标不允许手工录入，值由查询计算：
  - `pomodoro_min`：区间内 `pomodoro` 记录 `actualMin` 求和（kind=focus）
  - `focus_sessions`：区间内 focus 记录条数
  - `tasks_done`：区间内 `completedAt` 命中的任务数
- 周期汇总：`day` 直接取值；`week`/`month` 按 `periodRange` 累加（`aggregation` 决定 sum/max/avg/last）。

### 4.4 达标率

```
progress = up  ? clamp(value / target) : clamp((2*target - value) / target)  // down 方向
```
- 周期进度按「已过天数比例」对比，给一句人话：`本周已过 60%，你完成了 69%，领先`。

## 5. 验收

1. 开始番茄钟 → 刷新页面 → 剩余时间仍正确（误差 < 1s）。
2. 计时结束 → 写入 `pomodoro` 记录 → 今日统计 +1，KPI（如绑定）自动 +25。
3. 暂停 30s 再继续 → 总时长不被吃掉。
4. 完成一个绑定任务 → `tasks_done` 类 KPI 自动 +1。
5. KPI 手工打卡 → 卡片数值与图表即时更新。
6. 周/月周期切换 → 数值按周期重算。
7. 375 宽下按钮可点、圆环不溢出。
8. 单测：周期聚合、达标率（up/down 两个方向）、自动聚合三种来源。
