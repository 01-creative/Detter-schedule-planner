# T06 · 日历与日程

> 四象限回答「做什么」，日历回答「什么时候做」。两者共用同一张 `tasks` 表。

日 / 周 / 月三种视图，任务与事件同轴展示；拖拽改期；重复事件正确展开；手机上有可用的议程视图。

## 3. 视图

### 3.1 周视图（默认）

- 7 列 × 24 小时网格，每小时 56px，`06:00–24:00` 默认可见，可滚动到全天。
- 左侧时间轴（`06:00` 这样的粗粒度，每 2 小时一个标签）。
- 顶部：`‹ 本周 ›` + 「今天」+ 周范围（`11月24日 - 11月30日`）。
- 全天事件行（`allDay: true` 或 `kind: event` 且无时间）。
- 事件块：`position: absolute`，`top = (start - dayStart) / 60000 * pxPerMin`，`height = duration`；最小高度 22px。
- 时间重叠：同一列内按贪心分列（最多 3 列，超出显示 `+N`）。
- 当前时间指示线（红线 + 圆点），每 60s 更新。

### 3.2 日视图

- 单列，更宽，显示更多细节（地点、标签、目标色条）。

### 3.3 月视图

- 6×7 网格，每格显示最多 3 条（超出 `+N`），点击某天 → 切到日视图。
- 有任务的日期下方小圆点（按象限颜色）。

### 3.4 移动端（< 768）

- 默认「议程」列表视图：按天分组的任务流。
- 顶部切换：`议程 / 周 / 月`。
- 周视图横向滚动，每列最小 96px。

## 4. 交互

| 操作 | 行为 |
| --- | --- |
| 点击空白时段 | 新建事件（预填该时间，默认 1 小时），弹编辑器 |
| 拖拽事件块 | 改 `startAt/endAt`（保持时长），跨天允许；吸附 15 分钟 |
| 拖拽底边 | 调整 `endAt`（最小时长 15 分钟） |
| 点击事件 | 打开任务详情（复用 T03 的编辑器或独立 Sheet） |
| 双击月视图某天 | 切到日视图 |
| 键盘 `←/→` | 上一/下一周期；`T` 回到今天 |

- 拖拽用 pointer events，和 T03 同一套思路（不要在 move 里写库，`pointerup` 一次性提交）。
- 拖动时显示时间气泡（`14:30 - 15:30`）。
- 跨天拖拽：落在另一列时改日期，保留时分。

## 5. 重复事件

- 用 `rrule` 包展开：给定视图区间 `[from, to]`，对每个 `rrule` 非空的任务生成实例。
- 实例是**虚拟的**：不写库，渲染时带上 `occurrenceKey`（原始开始时间戳）。
- 点击虚拟实例 → 编辑时提供三个选项：
  ```
  ○ 只改这一次      → 写一条 recurrenceId=父id、occurrenceKey=原始时间的覆盖记录
  ○ 改此后所有      → 修改父任务的 rrule（并记录 UNTIL）
  ○ 改整个系列      → 直接改父任务
  ```
- 完成某一次：写一条 `status: done` 的实例记录（`recurrenceId` + `occurrenceKey`），展开时用实例覆盖父实例。
- 删除某一次：写一条 `status: dropped` 的实例记录（墓碑语义，不删父任务）。
- 时区：全部按本地时间展开；跨夏令时的地区（用户不在）不特殊处理，但代码里不要用 `toISOString()` 做日期计算。

## 6. 与四象限/收件箱的联动

- 日历里新建的任务，默认 `quadrant` 由 `deriveQuadrant` 推导（重要但无紧急 → Q2）。
- 在日历上拖动改变时间，不改象限。
- 任务详情里显示「在四象限中的位置」，可跳转。

---

## 7. 性能

- 只查询当前视图区间（`startAt` 或 `dueAt` 落在区间内，扩 1 天缓冲）。
- 月视图一次最多渲染 6×7×3 = 126 个块。
- 重复展开结果做 `useMemo`，依赖 `[tasks, viewRange]`，不要每次 render 重算。

---

## 8. 验收

1. 新建一个「明天 14:00-15:30」的事件 → 周视图正确出现在明天 14:00 位置。
2. 拖到 16:00 → 时间变 16:00-17:30，刷新后仍正确。
3. 拖底边拉长到 18:00 → `endAt` 更新。
4. 建一个「每周一 9:00」的重复事件 → 周视图每周一都出现。
5. 对其中一次「只改这一次」→ 只有那周变化，其它周不变。
6. 月视图显示圆点与 `+N`。
7. 375 宽：议程视图可用，切换周/月正常。
8. `←/→/T` 键盘导航生效。
