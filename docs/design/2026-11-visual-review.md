# Detter 视觉与交互评审（设计系统落地最后一层）

> 角色：视觉与交互质量负责人
> 范围：9 条路由 × 1440 / 768 / 375 × 浅色 / 深色，外加两套数据集（真实 11 条任务的种子库 + 全新空库）
> 方法：Playwright 全量截图 + DOM 几何/计算色探针 + 逐页人工目检；不改路由、不改信息架构、不新增依赖
> 环境：API `127.0.0.1:8781`，web `127.0.0.1:5194`；截图与探针原始数据在 `.qa/design-review/`
> 截图命名：`before-<路由>-<宽度>-<主题>.png`（有数据）/ `before-empty-…`（空库）；探针：`before-geometry.json`、`probe.json`、`../dr-probe2-out.json`

## 0. 结论

产品功能已经是完整的，问题不在"缺什么"，而在**同一套设计语言在不同页面上没有执行成同一个样子**：

1. **空态是最大的破绽**：四象限四格同一句话，插画因为一个 CSS 变量拼接错误而完全不可见；首屏统计在全 0 时仍然占着第一行；日历空周就是一张空网格。空账号第一次打开，看到的不是"引导"，是"没做完"。
2. **标题区没有统一节奏**：9 个页面的主标题顶部位置从 76px 到 99px 不等，字号 22/24 两种，眉题 11/12/缺失三种。用户说不出哪里不对，但每次切页都觉得"跳"。
3. **深色模式只做了"能看"，没做"好看"**：四象限降到灰褐、彼此难分；嵌套信息块（复盘的四个数字、设置的同步四宫格）与卡片同色，读不出块；边框 0.08 白几乎不可见。
4. **长页面没有节奏**：设置页 3852px（移动 5151px）15 张同权重卡片、间距全是 16px；复盘页 1768px（移动 2974px）间距全是 12px，"结论 / 数据 / 备注"三层读起来一样重。
5. **几处一眼可见的"破"**：象限滚动把第 5 张卡硬切成 8px 一条；KPI 无数据时 0 值折线贴在图表底边像渲染错误；专注页齿轮在 375 落到标题下方左侧；无目标任务的左侧色条是 `transparent`。

共记录 **23 条**问题，按 P0 / P1 / P2 排序。本轮只修其中**前 10 条**（含把深色两处合并为一次对比度修正），其余列在 §5 遗留，附不修的理由。

### 严重度判断标准

- 是否**在第一屏**出现；
- 是否让人误判"功能坏了/没做完"；
- 是否**反复**出现（每次打开、每次切换页面）；
- 修复是否只涉及视觉层（不动数据、不动交互路径）。

## 2. 本轮修哪 10 条，为什么先修这些

| 顺序 | 条目 | 为什么是它 |
| --- | --- | --- |
| 1 | D1 | 第一屏、第一次打开就出现；且是"坏了"（插画不可见），不是"不够美"。修它同时解决"四格同文"的占位感。 |
| 2 | D2 | 同样在第一屏；全 0 信息既占位置又降低信任感，改成有数据才显示/空数据给引导，成本极小。 |
| 3 | D3 | 任务卡是全站出现次数最多的组件；无目标色条隐形让 1/3 的卡片看起来"缺一块"，属于系统性观感。 |
| 4 | D4 | 影响全部 9 个页面、每次切页都发生；统一节奏是"最后一层质感"里性价比最高的一项。 |
| 5 | D5 + D10 | 深色是一等公民（设计规范 §1.5 有独立覆盖）；象限与嵌套块是深色下最明显的两处"糊"。合并为一次对比度修正（token + 局部描边），避免两次改同一批文件。 |
| 6 | D6 | 1440 首屏可见，且半张卡被切断是最典型的"没做完"信号；只加一层 mask，不动结构。 |
| 7 | D7 | 设置页是最长的页面（3852/5151px），无分组直接导致"找不到"，用户会认为功能缺失。 |
| 8 | D8 | 复盘页是产品的"总结仪式"，节奏平会让整页显廉价；移动端 banner 4 行也太占首屏。 |
| 9 | D9 | KPI 图表空态看起来像渲染错误，会直接影响对数据可信度的判断。 |
| 10 | D11 | 日历空周整屏无引导；与 D1 同属"空态没做完"，但影响面小于四象限，所以排第 10。 |

> 没有进前十的 D12–D23 并不是不重要，而是：要么被 D5 的 border token 顺手改善（D12/D22），要么属于局部细节、改动收益小于风险（D13–D21），要么需要动信息架构（D23 统一空态容器），留到下一轮。

## 3. 修复原则（自我约束）

1. **只用现有令牌**，不新增颜色/圆角/阴影；确实需要新值时优先调深色覆盖的现有变量。
2. **不改布局骨架**：四象限仍是 2×2、目标栏仍在右、设置仍是单列卡片、复盘仍是 12 栅格。
3. **不改信息架构**：不合并、不重排功能区块；设置页只加"分组标题"，卡片顺序保持原样。
4. **动效只碰 transform / opacity / mask**，时长沿用 `--dur-1..3` 与 `--ease-out`。
5. 每处修改都能用"改前/改后"截图或计算值复核，不靠主观描述。
