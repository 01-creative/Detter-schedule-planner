## 怎么读这份评审

每条问题都带**位置（file:line）+ 实测证据 + 严重度**，所以：

- 想复查：按 file:line 打开看现状；
- 想继续做：从 §5 的遗留表里挑，那里已经写清了「为什么这轮没做」；
- 想质疑：证据里有截图名与几何数值，能直接复现。

## 评审方法（可复用）

1. 9 条路由 × 1440/768/375 × 浅色/深色 全量截图；
2. 两套数据：真实种子数据（11 条任务）与**空库**——空态是最容易暴露"没做完"的地方；
3. DOM 几何与计算样式探针（标题 top 偏差、容器间距、颜色对比），不靠肉眼估；
4. 分工：P0（第一屏可见且像坏了）/ P1（反复出现、影响浏览）/ P2（局部细节）。
